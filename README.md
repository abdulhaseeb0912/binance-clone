# Binance Clone

A Binance-inspired cryptocurrency trading website developed using HTML, CSS, and JavaScript.

## Features

* Responsive Navigation Bar
* Hero Section
* Trending Cryptocurrency Section
* Cryptocurrency Market Table
* Buy Crypto Calculator
* Dark/Light Theme Toggle
* Responsive Design
* Modern User Interface

## Technologies Used

* HTML
* CSS
* JavaScript

## Project Structure

```text
binance-clone/
│
├── index.html
├── styles.css
├── app.js
└── assets/
```

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in any modern web browser.

No additional software or dependencies are required.
